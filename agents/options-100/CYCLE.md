# CYCLE.md — one trading cycle for options-100. Run by the "robinhood" session cron every minute (or by failsafe.sh).
Repo ~/code/TrevJT. S = agents/options-100/state. Account 836776765 (Agentic). VIX index id 3b912aa2-88f9-4682-8ae3-e39520bdf4db.
Times ET; machine clock is MDT (ET−2h). Be fast: minimum tool calls, no narration. Message Trevor ONLY on a fill, an error that needs him, or the daily report.

0. Guard. `TZ=America/New_York date "+%H:%M %u %F"`. Outside 09:24–16:06 ET or %u ≥ 6 → stop silently (write nothing).
   `touch S/cycle.lock` at start, `rm S/cycle.lock` at end (step 5). If repo-root STOP exists → cancel open orders, sell all at bid, journal "STOP", stop.
   Read S/day.json. If date ≠ today → step 1.
1. Pre-open (once per day). get_portfolio(836776765) → start_equity, cash. get_option_positions(nonzero) + get_option_orders(created today) → reconcile S/positions.json (adopt anything held: entry = avg cost, entered = "09:30", window "A").
   get_equity_historicals SPY,QQQ interval 5minute start_time = two sessions ago 13:30Z → `python3 agents/options-100/bot/score.py ingest SYM "<lines>"` per symbol, lines = begins_at,open,high,low,close,volume (compact, one per line).
   get_option_chains SPY and QQQ → today's expiry (YYYY-MM-DD) and chain ids. Event flags from PLAN.md (Oct 7: FOMC minutes 14:00 → no entries 13:30–14:15).
   Write S/day.json {date, start_equity, cash, trades_today:0, consecutive_losses:0, halted:false, regime:"NORMAL", regime_reason:"", regime_until:"", expiry:{SPY,QQQ}, chains:{SPY,QQQ}, flags:[]}. Journal "day_start".
2. Data. For SPY and QQQ: `python3 agents/options-100/bot/score.py last SYM` → get_equity_historicals start_time = that timestamp, interval 5minute → ingest only the new bars (usually 1–2 lines). VIX: get_index_quotes [id] → S/day.json.vix.
   `python3 agents/options-100/bot/score.py score SPY QQQ --now HH:MM`.
   News (every cycle, ONE WebSearch, standard mode): "stock market news today" → if a major headline in the last ~30 min (Fed, war/ceasefire, tariff, outage, index shock > 1%) → set regime NO_NEW_ENTRIES / CALLS_ONLY / PUTS_ONLY with reason and regime_until (HH:MM); journal "regime" on change only. Regime expires at regime_until.
3. Manage (before any entry). If S/positions.json non-empty: get_option_quotes [ids] → write S/marks.json {id:{bid,ask}, SPY:{vwap,close}, QQQ:{vwap,close}} (vwap/close from the score output).
   `python3 agents/options-100/bot/score.py manage S/positions.json S/marks.json --now HH:MM`.
   For SELL_ALL / SELL_HALF: review_option_order(account 836776765, legs [{option_id, side "sell", position_effect "close"}], quantity, type limit, price = "limit" from the output, chain_symbol, underlying_type equity) → place_option_order with the same params and a fresh ref_id. Update positions.json (peak, scaled:true after a half, remove when fully sold), day.json (trades_today, consecutive_losses, pnl_today). Journal each order {ts, action, symbol, contract, qty, limit, reason, pnl}.
   Open orders (get_option_orders state queued/confirmed): a sell unfilled 2 cycles → cancel_option_order, re-place at bid. A buy unfilled 1 cycle → cancel, skip.
4. Entry. ALL must hold: window A (09:40–11:00) or B (14:00–15:10); regime allows the direction; not halted; trades_today < 4; consecutive_losses < 3; pnl_today > −60% of start_equity; open positions < 2; equity ≥ $12; day flags pass; VIX 13–28; score bar_age_min ≤ 6.
   Decision: S ≥ +4 → call, S ≤ −4 → put; take the larger |S| of SPY/QQQ; never SPY and QQQ in the same direction at once.
   get_option_instruments(chain_symbol, expiration_dates = today's expiry, type) → pick 4–5 strikes OTM in the direction (calls above spot, puts below, $1 apart for SPY) → get_option_quotes → choose delta 0.10–0.20, mid 0.15–0.40, (ask−bid)/mid ≤ 0.12, bid ≥ 0.05, open_interest ≥ 500. None qualify → no trade.
   qty = floor(0.35 × equity / (mid × 100)), at least 1 only if mid × 100 ≤ cash; exposure after entry ≤ 70% of equity. If equity < $25: qty 1 and mid ≤ 0.25.
   review_option_order(buy, open, limit = mid rounded to 0.01, qty) → verify: no order_checks alerts, estimated cost ≤ cash, symbol/side/qty/price exact → place_option_order (same params, fresh ref_id). Append to S/positions.json {id, symbol, type, qty, entry, entered:"HH:MM", window, peak, scaled:false}. Journal "entry" with score, components, vix, regime, headline note.
   Pyramid: only once per position, if pnl ≥ +50% and |S| ≥ 5 → add 1 unit (same checks), then set stop_at_entry:true on that position.
   After EVERY place_option_order: call get_option_orders(order_id) and read state. If the state is anything like pending_approval / proposed / awaiting user (not queued/confirmed/filled/partially_filled), Trevor's "Trade approvals" toggle is still ON: PushNotification him ("Robinhood held the order as a proposal: turn Trade approvals OFF in the Agentic account, then reply go"), set day.json.halted=true with reason "approvals_on", and do no further entries until he replies. Exits of existing positions still run.
5. Heartbeat. Write S/heartbeat.json {ts (ISO), et:"HH:MM", source:"orchestrator", equity, cash, positions:n, last_action}. Append one line to S/cycle.log (HH:MM score_SPY score_QQQ vix regime positions action). `rm S/cycle.lock`.
6. End of day (first cycle at/after 16:05 ET, once). Confirm flat (positions empty). get_portfolio → end_equity. Write agents/options-100/reports/YYYY-MM-DD.md: pnl, trades, win rate, avg spread paid, biggest lesson, one proposed rule change. git add -A, git commit. Message Trevor the 5-line summary. Friday: add the week.
Journal file: journal/options-100.jsonl (one JSON object per line). Hard rules in PLAN.md override everything here. Two consecutive order-tool errors → stop entries, try to flatten at bid, tell Trevor (PushNotification).
