# CYCLE.md — one trading cycle (in-session cron, every minute, market hours). Repo: ~/code/TrevJT. S = agents/options-100/state. Times ET; machine clock is MDT = ET−2h.
Be fast: minimum tool calls, no narration. Message the user ONLY on a fill, an error that needs them, or the daily report.

0. Guard. `TZ=America/New_York date +%H:%M`. Outside 09:24–16:06 ET or weekend → stop silently. If repo-root STOP exists → cancel open orders, sell everything at bid, journal "STOP", stop. Read S/day.json; if its date ≠ today → do step 1.
1. Pre-open (once per day). get_portfolio → start_equity, cash. get_option_positions + get_option_orders → reconcile S/positions.json (adopt anything held, entry = avg cost). Event flags for today from PLAN.md. get_option_chains SPY and QQQ → today's expiry (or next if none). Write S/day.json {date, start_equity, trades_today:0, consecutive_losses:0, halted:false, regime:"NORMAL", expiry:{SPY,QQQ}, event_flags}. Journal "day_start".
2. Data. get_equity_historicals SPY and QQQ, interval 5minute, span covering ≥ 2 sessions → write raw to S/bars_SPY.json, S/bars_QQQ.json. VIX: get_index_quotes (VIX) else get_equity_quotes VIXY proxy → S/day.json.vix. Run `python3 agents/options-100/bot/score.py score S/bars_SPY.json S/bars_QQQ.json --now HH:MM`.
   News every cycle: `search` for market-moving headlines from the last 30 minutes. Major headline → set S/day.json.regime (NO_NEW_ENTRIES / CALLS_ONLY / PUTS_ONLY) with reason and an expiry time; journal "regime" on change only.
3. Manage (before any entry). For each S/positions.json entry: get_option_quotes → bid/ask. Write S/marks.json (contract quotes + SPY/QQQ {vwap, close} from the score output). Run `python3 agents/options-100/bot/score.py manage S/positions.json S/marks.json --now HH:MM`. Execute SELL_ALL / SELL_HALF: review_option_order (sell, close, qty, limit = mid − 1 tick; from 15:40 limit = bid) → place_option_order. Update positions.json (peak, scaled, remove when filled), day.json (trades_today, consecutive_losses, pnl). Journal each order: thesis, fill, pnl, lesson. Open orders: a sell unfilled 2 cycles → cancel, re-place at bid; a buy unfilled 1 cycle → cancel and skip.
4. Entry. Only if ALL: window A (9:40–11:00) or B (14:00–15:10); regime allows the direction; not halted; trades_today < 4; consecutive_losses < 3; day pnl > −60%; open positions < 2; equity ≥ $12; event-day filters pass; VIX 13–28. Decision from scores: S ≥ +4 → call, S ≤ −4 → put, prefer the larger |S| of SPY/QQQ, never both in the same direction. get_option_instruments (today's expiry, OTM strikes in direction) → get_option_quotes for 3–5 candidates → pick delta 0.10–0.20, mid 0.15–0.40, spread ≤ 12% of mid, bid ≥ 0.05, OI ≥ 500. If equity < $25: 1 contract ≤ $0.25. qty = floor(0.35 × equity / (mid × 100)), min 1 if mid × 100 ≤ cash; exposure after ≤ 70% of equity. review_option_order (buy, open, limit = mid rounded to tick) → verify no warnings, cost ≤ cash, symbol/side/qty exact → place_option_order. Append to S/positions.json {id, symbol, type, qty, entry, entered:"HH:MM", window, peak}. Journal "entry" with S, components, VIX, regime, headline summary. Pyramid: one add only, if a position is ≥ +50% and |S| ≥ 5; then stop_at_entry: true.
5. Heartbeat. Write S/heartbeat.json {ts, equity, positions, last_action}. Append one line to S/cycle.log.
6. End of day (first cycle at/after 16:05). Confirm flat. get_portfolio → end_equity. Write agents/options-100/reports/YYYY-MM-DD.md (pnl, trades, win rate, avg spread paid, biggest lesson, proposed rule change), git add + commit, message the user a 5-line summary. Friday: add the week.
Hard rules from PLAN.md override everything above. Two consecutive order-tool errors → stop entries, try to flatten, tell the user.
